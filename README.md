# Agenter

Локальный веб-чат с LLM: история диалогов, ручной и автоматический выбор модели, навыки (`SKILL.md`) и инструменты MCP. API работает на Node.js/Express/SQLite, интерфейс — на Vue 3/Vite.

## Быстрый запуск

Нужны Node.js 24+ и доступный OpenAI-совместимый endpoint модели. Для SSE-серверов из вашей локальной конфигурации запустите соответствующий MCP-прокси до старта API.

```powershell
npm install
Copy-Item .env.example .env
npm run dev:api
```

В другом терминале:

```powershell
npm run dev:web
```

Откройте адрес Vite (обычно `http://127.0.0.1:5173`). На macOS/Linux вместо `Copy-Item` используйте `cp .env.example .env`. Если нужен удалённый провайдер, укажите `OPENAI_API_KEY` в `.env` и перезапустите API. Для работы только с локальной моделью направьте все используемые маршруты Auto на `local`.

Подробная инструкция: [настройка провайдеров, маршрутизации, MCP и навыков](docs/configuration.ru.md).

При открытии приложения войдите или создайте аккаунт по логину и паролю.
У каждого пользователя отдельные чаты и история; модели, Skills, MCP и их
редактирование общие. Первый зарегистрированный пользователь получает
существующую историю из `DB_PATH`; последующие начинают с пустой истории.
Сессия действует 7 дней и отзывается кнопкой «Выйти». Для HTTPS установите
`AUTH_COOKIE_SECURE=true`. [Авторизация и хранение окружений](docs/configuration.ru.md#авторизация-и-окружения).

Откройте «Настройки» в боковой панели: базовую инструкцию, модели, маршруты Auto и MCP можно
редактировать и применять без перезапуска API. Навыки доступны для создания,
редактирования, отключения и удаления с резервной копией. При первом запуске
локальный `config/agenter.json` создаётся из `config/agenter.example.json`;
существующий конфиг сохраняется. Укажите реальное имя локальной модели в настройках:
шаблон использует `local-model`. Legacy-конфиги и их загрузчики удалены.
Ключи задаются ссылками `${ENV_NAME}`, значения остаются в `.env`.

В комплекте: веб-поиск, документация Context7, код за один проход, дизайн
интерфейса и ревью кода. [Выбор навыка и необходимых MCP](docs/skills.ru.md).
Context7 в шаблоне отключён; включите его и разрешите две функции документации.

Под вводом показаны занятое место, доступный объём для ввода и резерв ответа.
Во время запуска отображаются стадия и прошедшее время; ответ помечается как
предварительный на время самопроверки. В режиме Auto после маршрутизации видна
фактически выбранная модель. Можно ограничить историю текущего запроса. Кнопка
остановки отменяет генерацию; сохранённые вызовы инструментов и длительность
доступны при повторном открытии чата. При ошибке показывается безопасная причина
и следующий шаг; категория сохраняется в истории. Повтор запускается только
вручную и предупреждает, что внешнее действие могло уже выполниться. На узком
экране история открывается боковым меню, настройки — на весь экран.

Во время генерации можно открыть другой диалог и подготовить в нём черновик;
отправка второго запроса заблокирована. Плашка показывает, где идёт генерация,
и позволяет вернуться к ответу или остановить его. Чат с активным запуском нельзя
удалить до завершения или отмены.

В боковой панели история сгруппирована по дате и фильтруется по названию чата.
Новое название задаётся первым сообщением; свои чаты можно переименовать через
меню рядом с названием.

После ответа модель отдельно проверяет, выполнен ли исходный запрос. Если работа
может продолжиться, она делает ещё один проход с доступными инструментами; всего
допускается два таких продолжения и до десяти раундов вызовов инструментов.
Черновой ответ при продолжении заменяется новым в интерфейсе. Если проверка
недоступна, требуется ваше участие или достигнут предел, ответ сохраняется с
пометкой «Задача не завершена». Самопроверка — оценка модели, а не гарантия
правильности результата; каждый её проход расходует токены и время.

Ввод поддерживает `/model` (выбор модели), `/model ID`, `/model auto`, `/new`
и `/compact`. Сжатие создаёт резюме выбранной моделью, сохраняет исходную историю
и применяет резюме к следующим запросам. Навыки и MCP переключаются в сайдбаре;
добавление моделей и MCP доступно через отдельные формы в настройках.

Кнопка «Файл» и перетаскивание добавляют текстовые файлы (txt, md, html, json,
исходный код и др.). Текст из буфера длиной до 100 символов вставляется в поле
ввода; более длинный создаёт отдельную карточку с действием «Вставить в поле».
Текст вставляется у курсора рядом с черновиком; вложение удаляется после успешной
вставки. Вложения сохраняются в истории и учитываются в контексте.
Выберите «Ответ: Файл .md / Файл HTML» для документа; готовые файлы можно
скачать или открыть в браузере. Модель получает явный контракт выдачи полного
документа после инструкций навыка; пустой ответ или описание вместо HTML-файла
отображаются как ошибка/предупреждение. [Форматы, лимиты и предпросмотр](docs/text-files.ru.md).

## Главный экран

Главный экран оформлен по макету `agent-chat-home.pdf`: светлая рабочая область,
боковая панель и примеры запросов. Карточка примера добавляет текст в черновик,
сохраняя уже набранное, без автоматической отправки. В «Недавних диалогах» показаны
три последних обновлённых чата; «Все диалоги» раскрывает полный список. Модель и формат ответа доступны
под полем ввода, навыки и MCP — в боковой панели, редактирование — в настройках.

## Проверка

```powershell
npm run typecheck
npm run lint
npm test
```

Состояние подключённых серверов и список обнаруженных инструментов доступны после входа по `GET /api/mcp`. Недоступность отдельного MCP-сервера не останавливает API: он отображается со статусом `error`.
