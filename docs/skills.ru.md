# Практические навыки

Навык задаёт инструкции модели. Возможности обеспечивают выбранная модель и
разрешённые инструменты MCP. В сайдбаре выберите один навык и нужные серверы;
их настройка и редактирование доступны в «Настройках». Auto направляет
`research` в маршрут research, остальные навыки — в coding. Навык не меняет
модель принудительно; ручной выбор модели остаётся приоритетным.

| Навык / ID | Когда использовать | Нужные инструменты |
|---|---|---|
| Веб-поиск / `research` | Актуальные факты, сравнения, проверка источников | Поисковый MCP, например `ddg-search`, с поиском и чтением страниц |
| Документация Context7 / `context7-docs` | API библиотеки, настройка, примеры нужной версии | `context7`: `resolve-library-id`, `query-docs` |
| Код за один проход / `one-pass-code` | Полное решение с готовым кодом, состояниями UI и проверками | Вложения или чтение проекта; Context7 для API, исполнитель/браузер при наличии |
| Дизайн интерфейса / `claude-design` | Лендинг, компонент, адаптивный HTML-прототип | Достаточно описания/вложений; браузер для проверки при наличии |
| Ревью кода / `code-review` | Ошибки и регрессии с конкретными сценариями | Вложения/diff или чтение репозитория |

Веб-поиск использует доступный поисковый сервис: `ddg-search` обращается к
DuckDuckGo. Google не требуется. Ответ должен содержать ссылки на действительно
прочитанные источники и различать подтверждённые сведения и выводы модели.

«Код за один проход» означает полный результат без заглушек, но включает
необходимые проверки и исправления. Если в каталоге нет записи файлов или
исполнителя, модель выдаёт код и команды для запуска, а не сообщает о
вымышленном создании файлов и прохождении тестов. Чтение через repo-context
не предоставляет возможность редактировать локальный репозиторий.

Для самостоятельного прототипа выберите «Ответ: Файл HTML». Модель должна
вернуть весь документ со встроенными CSS/JS. Предпросмотр блокирует внешние
запросы, поэтому CDN, загрузка данных и внешние шрифты не являются рабочими
зависимостями. Для исследования или документа с кодом подходит «Файл .md».

## Context7

В `config/agenter.example.json` есть отключённый рецепт stdio:

```json
{
  "transport": "stdio",
  "command": "npx",
  "args": ["-y", "@upstash/context7-mcp"],
  "enabled": true,
  "allowedTools": ["resolve-library-id", "query-docs"]
}
```

Добавьте/включите сервер в настройках, проверьте подключение и сохраните.
Первый запуск скачивает пакет из npm и может превысить таймаут проверки:
заранее выполните `npx -y @upstash/context7-mcp --help`, затем повторите проверку.
Нужны Node.js и доступ к npm/сервису Context7. На Windows, если npx не находится,
можно использовать `command: "cmd"`, args `["/c", "npx", "-y", "@upstash/context7-mcp"]`.
Затем выберите Context7 в сайдбаре чата. Само обнаружение функций подтверждает
только подключение MCP; получение документации проверяется отдельным вызовом.

Ключ необязателен для начальной работы; при ограничениях добавьте
`CONTEXT7_API_KEY` в `.env` и поле env сервера
`{ "CONTEXT7_API_KEY": "${CONTEXT7_API_KEY}" }`, затем перезапустите API.
Не помещайте значение ключа в args или конфиг. Для вызова сначала разрешается
ID библиотеки (`libraryName`, `query`), затем запрашивается документация
(`libraryId`, `query`). Версия выбирается по каталогу, а не по догадке.
Официальные источники: [Context7 MCP](https://github.com/upstash/context7),
[настройка клиентов](https://context7.com/docs/resources/all-clients).

## Примеры запросов

- Веб-поиск: «Сравни три локальных OpenAI-compatible сервера по работе с tools.
  Используй актуальную документацию и дай ссылки».
- Context7: «Найди документацию Vue 3 по watch с отменой устаревшего запроса;
  объясни совместимость с Vue 3.5».
- Код за один проход: «По приложенному компоненту добавь поиск и пустое состояние,
  сохрани Vue/TypeScript, верни полный файл и проверки».
- Дизайн: «Создай адаптивную страницу списка задач. Добавление, фильтр и удаление
  должны работать в браузерном предпросмотре. Ответ — HTML».
- Ревью: «Проверь приложенный diff на регрессии отмены запросов; укажи сценарий
  воспроизведения и минимальное исправление».

При прямом редактировании SKILL.md перезапустите API, чтобы перечитать каталог;
изменение через редактор настроек применяется сразу. Исходный пользовательский
`claude-design` перед обновлением сохранён локально в SKILL.md.bak.

Следующие полезные кандидаты: диагностика ошибок с тестами и работа с текстом
(редактура, резюме, перевод). Они не входят в текущий набор.
